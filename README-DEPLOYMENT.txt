ANTIC R.O SYSTEM — GitHub Pages deployment notes

1. Upload the contents of this project folder to the root of your GitHub repository.
2. In GitHub, open Settings > Pages, choose Deploy from a branch, select the main branch and /(root), then Save.
3. Your website URL will be https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ (or https://YOUR-USERNAME.github.io/ if the repository is named YOUR-USERNAME.github.io).
4. After publishing, replace the example URL in Open Graph/social metadata with the exact live URL and absolute image URL.
5. Add sitemap.xml only after you know the exact live URL; do not leave placeholder URLs in the sitemap.
6. Replace Facebook/Instagram links only when you have the real official profile URLs. The current footer avoids linking to generic social homepages.
7. Check the published site on a phone and test the call, WhatsApp, catalogue and service-request links.

Important:
- The service form opens WhatsApp with the customer's entered details. It does not store form submissions on a server.
- Verify business address, opening hours, email, phone number and all service claims before public launch.
- The product catalogue is an HTML page, not a PDF; its link label has been corrected accordingly.
